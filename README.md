# 공간 작품 매칭 · VIP 초대장

**https://private-art-collection.netlify.app**

큐레이터가 상담(TM)을 마친 고객에게 **개인 전용 링크**를 발급하고,
고객은 그 링크로 12문항 공간 진단을 진행하는 초대제 페이지입니다.

- `index.html` — 페이지 전체 (폰트·작품 이미지·QR 라이브러리 모두 내장된 단일 파일)
- 응답과 발급 내역은 구글 시트로 수집됩니다.

## 사용법

| 화면 | 들어가는 법 |
|---|---|
| 고객 초대장 | 발급된 개인 링크 (`.../#v=...`) |
| 큐레이터 | 첫 화면 하단 **큐레이터 화면** → 접속 코드 |

큐레이터 화면에서 이름·호칭·연락처를 넣고 **초대 링크 만들기**를 누르면
링크가 클립보드에 복사되고, 발급 내역이 구글 시트 `초대` 탭에 기록됩니다.
대면 미팅에서는 **QR** 버튼으로 띄워 고객 휴대폰으로 스캔하게 하면 됩니다.

처음 한 번은 큐레이터 화면의 **배포 주소** 칸에 이 사이트 주소를 넣어 주세요.
그 주소를 기준으로 발급 링크와 QR이 만들어집니다.
